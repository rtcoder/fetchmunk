# Fetchmunk — kolejnych 50 zadań

> **For agentic workers:** Use executing-plans for integration; dispatching-parallel-agents for independent backend, presentation and packaging domains. User explicitly approved autonomous execution in advance.

**Goal:** Użyteczna alfa macOS z lepszą historią, diagnostyką i kompletniejszą paczką.
**Architecture:** Zachowujemy JSONL, osobny worker gallery-dl, SQLite i ograniczone strony SwiftUI. Niezależne obszary mają rozłączne pliki; koordynator integruje AppModel/MainView i uruchamia wspólne testy.
**Tech Stack:** SwiftUI/AppKit, Python/gallery-dl/SQLite, PyInstaller, GitHub Actions.
**Spec:** `docs/superpowers/specs/2026-10-21-alpha-usability.md`.

## Global Constraints

macOS arm64; deployment target13; bez nowych silników, kont i chmury.
Nie odczytujemy prywatnych sesji. Nie usuwamy danych. Bez publikowania surowych URL/logów.
Nie obiecujemy procentu całej galerii. Notaryzacja/aktualizator/logowanie pozostają poza tym etapem.

## Review Focus

Dosłowne znaki SQL w wyszukiwaniu; cursor z innego zapytania; spóźnione odpowiedzi GUI;
sekrety w raporcie; brak pliku licencji w paczce. Odpowiadają za nie testy poniższych grup.

## Weryfikacja i zależności

Każdy implementer najpierw odtwarza testem istotne nowe zachowanie (RED), następnie
wdraża i sprawdza GREEN. Nie piszemy testów kopiujących czysto wizualne modyfikatory.
Backend i prezentacja nie modyfikują AppModel/MainView; pakowanie nie modyfikuje GUI/backendu.
Końcowy raport oddzieli wykonane zadania od blokad środowiska. Nie ruszamy tagu v0.1.0.
